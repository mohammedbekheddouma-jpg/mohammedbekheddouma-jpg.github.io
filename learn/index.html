01 / المبادئخمس قواعد تحدد الفرق

الأساسيات لا تُختصر، والمشاريع هي التي تُثبّتها. من يبدأ بالإطار قبل اللغة يبقى ينسخ ولا يفهم.

الأساس أولاًلغة، منطق، بيانات، ثم إطار العمل. الإطار يتغير، والأساس يبقى.
مشروع بعد كل مفهوملا تنتقل لدرس جديد قبل أن تبني شيئاً صغيراً بما تعلمته.
مسار واحد في كل مرةفرونت أو باك أو موبايل. التشتت يبطئك أكثر من أي شيء آخر.
Git من اليوم الأولكل ما تبنيه في مستودع، حتى التمارين. تاريخك البرمجي هو سيرتك.
اقرأ الوثائقالوثيقة الرسمية أصدق من عشر فيديوهات. تعلّم كيف تقرأها.

02 / المساراتكل تخصص ومحتواه

سبعة مسارات. اختر مساراً رئيسياً ومساراً ثانوياً فقط، والباقي يُضاف بعد أن تصل إلى مستوى مقبول في الأول.

تطوير الويب

المسار الكامل

المسار الأشمل والأنسب للانطلاق، لأن الواجهة تعمل على كل الأجهزة دون تثبيت.

  • HTML الدلالي: عناصر، نماذج، بنية الصفحة
  • CSS: الصندوق، Flexbox، Grid، التصميم المتجاوب
  • JavaScript: المتغيرات، الدوال، المصفوفات، الكائنات، DOM
  • fetch و async/await واستهلاك واجهات API
  • Git وGitHub: الفروع، الدمج، طلبات السحب
  • إطار واجهة واحد: React مع Vite
  • باك إند: ASP.NET Core أو Node/Express
  • قاعدة بيانات SQL: تصميم الجداول والاستعلامات
  • النشر: GitHub Pages للواجهة، Azure أو Render للخادم
أول مشروع: موقع شخصي ثابت، ثم واجهة تواصل ترسل بياناتها إلى API بسيط بنيته أنت.

الفرونت إند

الواجهة

ما يراه المستخدم ويعمل عليه. المطلوب فيه حسّ التصميم مع دقة التنفيذ.

  • HTML: الدلالة، إتاحة الوصول، النماذج
  • CSS متقدّم: المتغيرات، الحركات، الاستجابة
  • Tailwind CSS بعد إتقان CSS لا قبله
  • JavaScript: الأحداث، الوحدات، التخزين المحلي
  • TypeScript: الأنواع، الواجهات، الأدوية الجنيسة
  • React: الحالة، الخطافات، التوجيه، النماذج
  • إدارة الحالة وتجربة الاستخدام والأداء
  • أدوات: npm، Vite، DevTools، Lighthouse
أول مشروع: لوحة تحكم عربية RTL تستهلك API عاماً، مع بحث وفرز وتحميل تدريجي.

الباك إند

المنطق والبيانات

قلب التطبيق: المنطق، البيانات، الأمان. أقرب مسار لخبرتك في C#.

  • HTTP وREST: الأفعال، رموز الحالة، الرؤوس
  • C# وASP.NET Core: المتحكمات، الخدمات، الحقن
  • SQL Server: الجداول، العلاقات، الفهارس، المعاملات
  • Entity Framework Core: الهجرة والاستعلامات
  • مصادقة: JWT، تشفير كلمات المرور، الأدوار
  • جودة: تحقق من المدخلات، سجلات، معالجة الأخطاء، اختبارات
  • أداء: فهارس، تخزين مؤقت، مهام خلفية
  • أمان التطبيقات: OWASP العشرة الأوائل
أول مشروع: API لمهام المستخدمين بمصادقة JWT، قاعدة بيانات، اختبارات وحدة، وتوثيق Swagger.

تطوير الموبايل

الهاتف

اختر منصة واحدة أولاً. المنطق واحد، والأدوات مختلفة.

  • اختيار المسار: Flutter أو React Native أو أصلي
  • بنية الشاشات والتنقل بينها
  • إدارة الحالة ومزامنة الواجهة
  • تخزين محلي: SQLite أو AsyncStorage
  • استهلاك API والتعامل مع ضعف الشبكة
  • الإشعارات والصلاحيات
  • البناء والنشر في Play Store أو App Store
أول مشروع: تطبيق مهام يعمل بلا إنترنت ويزامن البيانات عند عودة الاتصال.

تطوير الديسكتوب

سطح المكتب

أقرب مسار إلى خلفيتك الحالية في C# وتطبيقات Windows.

  • اختيار التقنية: WPF أو WinUI 3 أو Tauri
  • نمط MVVM وفصل الواجهة عن المنطق
  • الارتباط بالبيانات والتحقق من المدخلات
  • الخيوط والمهام والعمليات الطويلة بلا تجميد
  • قاعدة بيانات محلية SQLite وEF Core
  • الحزم والتثبيت والتحديث التلقائي
  • التواصل مع خدمات خارجية وAPI
أول مشروع: برنامج سطح مكتب لإدارة الفواتير مع قاعدة بيانات محلية وتصدير PDF.

DevOps

التشغيل والنشر

ليس لغة تتعلمها، بل طريقة عمل تجعل ما بنيته يعمل ويكبر بأمان.

  • Linux: الصلاحيات، العمليات، الشبكة، systemd
  • Bash وسكربتات الأتمتة
  • Git في الفريق: الفروع، المراجعة، الإصدارات
  • Docker: الصور، الحاويات، docker-compose
  • CI/CD مع GitHub Actions: بناء واختبار ونشر
  • سحابة: Azure أو AWS، خدمات الحوسبة والتخزين
  • البنية كرمز: Terraform
  • المراقبة والسجلات والتنبيهات والأمان وإدارة الأسرار
أول مشروع: صوّر أحد تطبيقاتك في Docker وانشره تلقائياً عبر GitHub Actions عند كل دفع.

علوم البيانات

التحليل والذكاء

المهارة الحاسمة فيها الإحصاء وتنظيف البيانات، لا النماذج المتقدمة.

  • Python: المتغيرات، الدوال، الهياكل، الملفات
  • NumPy وPandas لتنظيف البيانات وتحليلها
  • SQL: تجميع البيانات وربط الجداول
  • إحصاء: التوزيعات، الارتباط، اختبار الفرضيات
  • التصوير البياني: matplotlib وseaborn
  • تعلم الآلة مع scikit-learn: انحدار، تصنيف، تقييم
  • التعلم العميق لاحقاً: PyTorch
  • نشر النموذج ومراقبته
أول مشروع: تحليل مجموعة بيانات حقيقية، واستخلاص ثلاث نتائج قابلة للتنفيذ بنموذج تنبؤي بسيط.
